---
title: "create_vault"
description: "Record billing terms for a (user, merchant) pair. Moves no funds."
---

```rust
pub fn create_vault(
    env: Env,
    user: Address,
    merchant: Address,
    token: Address,
    amount_per_interval: i128,
    interval_seconds: u64,
)
```

**Auth:** `user.require_auth()`

## Parameters

<ParamField path="user" type="Address" required>
  The subscriber. Must sign. This is the account tokens are pulled from.
</ParamField>

<ParamField path="merchant" type="Address" required>
  The only address that can call `pull_funds` on this vault.
</ParamField>

<ParamField path="token" type="Address" required>
  SEP-41 token contract, for example the USDC SAC.
</ParamField>

<ParamField path="amount_per_interval" type="i128" required>
  Raw units pulled each cycle. `290000000` = 29 USDC. Must be greater than zero.
</ParamField>

<ParamField path="interval_seconds" type="u64" required>
  Minimum ledger-time gap between pulls. Must be greater than zero.
</ParamField>

## Effects

1. Writes `VaultData { token, amount_per_interval, interval_seconds, last_pull_timestamp: 0 }` under `VaultKey { user, merchant }` in persistent storage.
2. Overwrites any vault that already exists for the same pair.

## Errors

Both checks run after `user.require_auth()` and before anything is written, so a rejected call leaves any existing vault untouched.

| Message | Cause | Fix |
|---|---|---|
| `amount_per_interval must be positive` | `amount_per_interval <= 0` | Pass an amount greater than zero, in raw token units |
| `interval_seconds must be greater than zero` | `interval_seconds == 0` | Pass an interval of at least 1 second |

See [contract errors](/contracts/errors) for the full list and how to catch them in simulation.

## Preconditions for later pulls

`create_vault` does **not** check the allowance. It succeeds even without an allowance, but every pull will fail until the user calls `approve` on the token with Orbit as the spender.

  <Tab title="TypeScript">

    Install the SDK and Freighter browser API with `npm install @stellar/stellar-sdk @stellar/freighter-api`. Connect Freighter to Testnet before running this subscriber-side example.

    ```ts
    import { rpc, Contract, TransactionBuilder, Address, nativeToScVal } from "@stellar/stellar-sdk";
    import { getAddress, signTransaction } from "@stellar/freighter-api";

    const ORBIT = "CAZBZBUWBSQYK2RZ6WHMXVDLIQHSU5WD7ANZYL6HLNSCRUOTNYCDYQNG";
    const RPC_URL = "https://soroban-testnet.stellar.org";
    const NETWORK_PASSPHRASE = "Test SDF Network ; September 2015";
    const server = new rpc.Server(RPC_URL);

    export async function createVault(merchant: string, token: string) {
      const { address: subscriber } = await getAddress();
      const account = await server.getAccount(subscriber);
      const transaction = new TransactionBuilder(account, {
        fee: "100000",
        networkPassphrase: NETWORK_PASSPHRASE,
      })
        .addOperation(
          new Contract(ORBIT).call(
            "create_vault",
            new Address(subscriber).toScVal(),
            new Address(merchant).toScVal(),
            new Address(token).toScVal(),
            nativeToScVal(290000000n, { type: "i128" }),
            nativeToScVal(2592000n, { type: "u64" }),
          ),
        )
        .setTimeout(60)
        .build();

      const simulation = await server.simulateTransaction(transaction);
      if (rpc.Api.isSimulationError(simulation)) {
        throw new Error(simulation.error);
      }

      const prepared = await server.prepareTransaction(transaction);
      const { signedTxXdr } = await signTransaction(prepared.toXDR(), {
        networkPassphrase: NETWORK_PASSPHRASE,
      });
      const signed = TransactionBuilder.fromXDR(signedTxXdr, NETWORK_PASSPHRASE);
      const submitted = await server.sendTransaction(signed);
      return server.pollTransaction(submitted.hash);
    }
    ```

    `290000000` is 29 USDC in raw units, not a decimal amount. Simulation happens before Freighter is asked to sign.
