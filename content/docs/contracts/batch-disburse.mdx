---
title: "batch_disburse"
description: "Pay many recipients from one sender in a single atomic invocation."
---

```rust
pub fn batch_disburse(env: Env, sender: Address, token: Address, splits: Vec<PaymentSplit>)
```

**Auth:** `sender.require_auth()`

## Parameters

<ParamField path="sender" type="Address" required>
  The treasury paying out. Must sign and must have approved Orbit for at least the sum of all splits.
</ParamField>

<ParamField path="token" type="Address" required>
  SEP-41 token to pay in.
</ParamField>

<ParamField path="splits" type="Vec<PaymentSplit>" required>
  Ordered list of `{ recipient: Address, amount: i128 }`. Amounts are raw units.
</ParamField>

## Execution

```rust
sender.require_auth();

assert!(!splits.is_empty(), "splits must not be empty");

for split in splits.iter() {
    assert!(split.amount > 0, "split amount must be positive");
}

let token_client = token::Client::new(&env, &token);
let recipient_count = splits.len();
let mut total_amount: i128 = 0;

for split in splits.into_iter() {
    total_amount = total_amount
        .checked_add(split.amount)
        .expect("Total amount overflow");

    token_client.transfer_from(
        &env.current_contract_address(),
        &sender,
        &split.recipient,
        &split.amount,
    );
}

env.events().publish(
    (Symbol::new(&env, "batch_disbursed"), sender),
    (token, recipient_count, total_amount),
);
```

## Validation

Input validation runs before any transfer is executed. Every split amount is checked upfront, so an invalid split anywhere in the list causes the entire transaction to revert before any tokens move:

| Message | Cause | Fix |
|---|---|---|
| `splits must not be empty` | `splits` has no entries | Provide at least one recipient and amount |
| `split amount must be positive` | Any split has `amount <= 0` | Pass an amount greater than zero, in raw token units |
| `Total amount overflow` | The sum of split amounts overflows `i128` | Keep the total batch payout within `i128::MAX` |

See [contract errors](/contracts/errors) for the full list of errors and simulation instructions.

## Properties

- **Atomic:** a failure on split `k` reverts splits `0..k`.
- **Stateless:** writes nothing to Orbit storage.
- **Bounded by resources**, not by a constant: large batches can go over the transaction's CPU or ledger-write budget. Simulate first, and split the batch if needed.

  <Tab title="TypeScript">

    This example runs on a trusted server using the treasury keypair. Store `TREASURY_SECRET` securely and never ship it to a browser. Install `@stellar/stellar-sdk`.

    ```ts
    import { rpc, Contract, TransactionBuilder, Address, Keypair, xdr, nativeToScVal } from "@stellar/stellar-sdk";

    const ORBIT = "CAZBZBUWBSQYK2RZ6WHMXVDLIQHSU5WD7ANZYL6HLNSCRUOTNYCDYQNG";
    const RPC_URL = "https://soroban-testnet.stellar.org";
    const NETWORK_PASSPHRASE = "Test SDF Network ; September 2015";
    const server = new rpc.Server(RPC_URL);

    function paymentSplit(recipient: string, amount: bigint) {
      return xdr.ScVal.scvMap([
        new xdr.ScMapEntry({
          key: xdr.ScVal.scvSymbol("recipient"),
          val: new Address(recipient).toScVal(),
        }),
        new xdr.ScMapEntry({
          key: xdr.ScVal.scvSymbol("amount"),
          val: nativeToScVal(amount, { type: "i128" }),
        }),
      ]);
    }

    export async function batchDisburse(token: string, recipientA: string, recipientB: string) {
      const treasury = Keypair.fromSecret(process.env.TREASURY_SECRET!);
      const sender = treasury.publicKey();
      const splits = xdr.ScVal.scvVec([
        paymentSplit(recipientA, 100000000n),
        paymentSplit(recipientB, 50000000n),
      ]);
      const account = await server.getAccount(sender);
      const transaction = new TransactionBuilder(account, {
        fee: "100000",
        networkPassphrase: NETWORK_PASSPHRASE,
      })
        .addOperation(
          new Contract(ORBIT).call(
            "batch_disburse",
            new Address(sender).toScVal(),
            new Address(token).toScVal(),
            splits,
          ),
        )
        .setTimeout(60)
        .build();

      const simulation = await server.simulateTransaction(transaction);
      if (rpc.Api.isSimulationError(simulation)) {
        throw new Error(simulation.error);
      }

      const prepared = await server.prepareTransaction(transaction);
      prepared.sign(treasury);
      const submitted = await server.sendTransaction(prepared);
      return server.pollTransaction(submitted.hash);
    }
    ```

    The two splits use raw units: `100000000` is 10 USDC and `50000000` is 5 USDC. Simulate before signing; the contract executes the transfers atomically.
