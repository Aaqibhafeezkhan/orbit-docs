---
title: "pull_funds"
description: "Collect one billing cycle from a subscriber's wallet into the merchant's."
---

```rust
pub fn pull_funds(env: Env, user: Address, merchant: Address)
```

**Auth:** `merchant.require_auth()`

## Parameters

<ParamField path="user" type="Address" required>
  The subscriber whose vault is being charged.
</ParamField>

<ParamField path="merchant" type="Address" required>
  Must sign. Together with `user`, it forms the vault key.
</ParamField>

## Execution

```rust
merchant.require_auth();

let key = VaultKey { user, merchant };
let mut vault: VaultData = storage.get(&key).expect("Vault does not exist");
let now = env.ledger().timestamp();

if vault.last_pull_timestamp != 0 {
    assert!(now >= vault.last_pull_timestamp + vault.interval_seconds,
            "Too early to pull funds");
}

token.transfer_from(&orbit, &user, &merchant, &vault.amount_per_interval);

vault.last_pull_timestamp = now;
storage.set(&key, &vault);
```

## Guards

| Check | Enforced by | On failure |
|---|---|---|
| Merchant signed | Soroban host | auth error |
| Vault exists | Orbit | `Vault does not exist` |
| Interval elapsed (skipped on first pull) | Orbit | `Too early to pull funds` |
| Allowance ≥ amount and not expired | Token SAC | token error |
| Balance ≥ amount | Token SAC | token error |

## Effects

- Transfers `amount_per_interval` from `user` straight to `merchant`.
- Reduces the allowance by `amount_per_interval`.
- Sets `last_pull_timestamp = now`.

If anything fails, all of it reverts and `last_pull_timestamp` stays the same.

  <Tab title="TypeScript">

    This is a server-side keeper/merchant operation. Keep the merchant secret in a server-side environment variable; never expose it in browser code. Install `@stellar/stellar-sdk`.

    ```ts
    import { rpc, Contract, TransactionBuilder, Address, Keypair } from "@stellar/stellar-sdk";

    const ORBIT = "CAZBZBUWBSQYK2RZ6WHMXVDLIQHSU5WD7ANZYL6HLNSCRUOTNYCDYQNG";
    const RPC_URL = "https://soroban-testnet.stellar.org";
    const NETWORK_PASSPHRASE = "Test SDF Network ; September 2015";
    const server = new rpc.Server(RPC_URL);

    export async function pullFunds(subscriber: string) {
      const keeper = Keypair.fromSecret(process.env.KEEPER_SECRET!);
      const merchant = keeper.publicKey();
      const account = await server.getAccount(merchant);
      const transaction = new TransactionBuilder(account, {
        fee: "100000",
        networkPassphrase: NETWORK_PASSPHRASE,
      })
        .addOperation(
          new Contract(ORBIT).call(
            "pull_funds",
            new Address(subscriber).toScVal(),
            new Address(merchant).toScVal(),
          ),
        )
        .setTimeout(60)
        .build();

      const simulation = await server.simulateTransaction(transaction);
      if (rpc.Api.isSimulationError(simulation)) {
        throw new Error(simulation.error);
      }

      const prepared = await server.prepareTransaction(transaction);
      prepared.sign(keeper);
      const submitted = await server.sendTransaction(prepared);
      return server.pollTransaction(submitted.hash);
    }
    ```

    The keeper keypair signs only after simulation and transaction preparation. The contract still enforces the vault interval, allowance, balance, and merchant authorization.
